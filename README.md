## 🎯 Core Concepts Covered

* **Python Fundamentals:** Dynamic typing, user input/output, typecasting, operators, and string manipulation.
* **Control Flow & Functions:** Conditional logic (`if-elif-else`), loops, recursion, `*args` & `**kwargs`, and lambda functions.
* **Data Structures:** Lists, list comprehensions, tuples, sets, and dictionary operations.
* **Object-Oriented Programming (OOP):** Classes, objects, `__init__` constructors, encapsulation, inheritance, and polymorphism.
* **File & Exception Handling:** Reading/writing text and JSON files safely using `with open()` and `try-except-finally` blocks.

## 📋 Detailed Program List

### 🟢 1. Basics, Loops & Functions
* **01. Hello World & Basic I/O (`hello_world.py`)** – Displays formatted output and captures user input using `print()` and `input()`.
* **02. Arithmetic Calculator (`calculator.py`)** – Performs addition, subtraction, multiplication, division, exponentiation, and modulus operations.
* **03. Odd or Even & Leap Year Checker (`number_checks.py`)** – Evaluates number properties and leap years using conditional logic.
* **04. Prime Number Verifier (`prime_check.py`)** – Checks if an integer is prime and prints all prime numbers within a given range.
* **05. Fibonacci Sequence Generator (`fibonacci.py`)** – Generates the Fibonacci series up to $N$ terms using both iterative loops and recursion.
* **06. Factorial & Armstrong Number (`math_programs.py`)** – Computes factorials and verifies whether a number is an Armstrong number.

### 🔵 2. Data Structures & Strings
* **07. Palindrome & Anagram Checker (`string_checks.py`)** – Uses string slicing and frequency counting to verify palindromes and anagrams.
* **08. List Operations & Comprehensions (`list_ops.py`)** – Demonstrates sorting, slicing, filtering, and concise list comprehensions.
* **09. Dictionary Contact Book (`contact_dict.py`)** – Stores, searches, updates, and deletes contact details using key-value pairs.
* **10. 2D List Matrix Operations (`matrix_ops.py`)** – Performs matrix addition, multiplication, and transposition using nested lists.

### 🟣 3. OOP, File Handling & DSA
* **11. Student Management Class (`student_oop.py`)** – Demonstrates class attributes, instance methods, and object creation.
* **12. Bank Account Simulation (`bank_oop.py`)** – Implements OOP encapsulation and inheritance for deposits, withdrawals, and balance checks.
* **13. File Reader & Word Counter (`word_count.py`)** – Reads external `.txt` files to count total lines, words, and character frequencies.
* **14. Searching & Sorting Algorithms (`search_sort.py`)** – Implements Linear Search, Binary Search, Bubble Sort, and Quick Sort.

## 🛠️ Mini-Projects Included

* **🎲 1. Number Guessing Game (`number_guessing.py`)**
  * **Overview:** An interactive terminal game built with the `random` module where players guess a secret number within limited attempts using dynamic high/low hints.
* **📝 2. CLI To-Do List Manager (`todo_app.py`)**
  * **Overview:** A persistent task manager allowing users to add, view, complete, and delete tasks stored in a local file.
* **🔐 3. Custom Password Generator (`password_gen.py`)**
  * **Overview:** Generates secure, randomized passwords of custom length combining uppercase, lowercase, digits, and special symbols.
* **✊✋✌️ 4. Rock, Paper, Scissors (`rock_paper_scissors.py`)**
  * **Overview:** A command-line game against the computer complete with round tracking, input validation, and scoreboards.

## 🚀 Getting Started

### Prerequisites
Ensure you have **Python 3.x** installed on your system:

```bash
python --version
```

### Cloning and Running
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/sanketkori8529/PythonwithSanket.git](https://github.com/sanketkori8529/PythonwithSanket.git)
   ```
2. **Navigate to the directory:**
   ```bash
   cd PythonwithSanket
   ```
3. **Run any Python program:**
   ```bash
   python <filename>.py
   ```
